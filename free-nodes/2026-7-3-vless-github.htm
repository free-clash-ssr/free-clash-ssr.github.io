实战教程：三步打造智能科学上网环境

第一步：基础网络搭建

将Mi WIFI Pro放置在家庭中心位置，接通电源后，用网线连接光猫的LAN口和路由器的WAN口。首次开机时，路由器会创建一个名为"Xiaomi_XXXX"的开放WiFi，连接后自动跳转到设置页面。这里建议：

  1. 修改默认管理员密码（避免使用简单数字组合）

在完成基础设置后，我们需要进入"开发者模式"：

  1. 登录管理界面（192.168.31.1）

获得SSH权限后，我们就可以像给智能手机刷机一样，为路由器安装各种增强功能。这里推荐使用ShellClash这款开源工具，它相比原厂固件提供的VPN功能更加强大和灵活。

Q：为什么YouTube加载速度很慢？
A：尝试切换不同地区的节点；检查是否开启了UDP转发（影响视频流传输）；确认路由器CPU负载是否过高。

Q：某些国内网站无法访问？
A：检查分流规则是否正确；尝试关闭"绕过中国大陆IP"功能；清除DNS缓存。

Q：如何保证长期稳定使用？
A：定期更新ShellClash到最新版本；备份配置文件；设置定时重启（每周一次）。

FAQ

V2Ray 的 Routing 设置可以实现什么？
V2Ray 的 Routing 系统支持基于域名、IP、端口或协议的智能分流。用户可以指定特定网站直连、部分服务走代理，还能创建黑白名单，实现灵活的网络访问控制。
Clash 策略组如何实现节点优先级切换？
用户可以在 Clash 策略组中设置节点优先级，结合规则文件自动选择延迟低、稳定性高的节点处理流量。优化网页浏览、视频播放和游戏访问速度，提高整体网络效率。
PassWall2 能运行在哪些设备上？
PassWall2 是基于 OpenWRT 的插件，只要路由器支持该固件，就能安装运行。常见型号如小米路由、斐讯、软路由都可以使用，通过 Web 界面操作，适合家庭网络使用场景。
Hysteria2 多路复用如何提升短连接性能？
多路复用允许多个短连接共享同一通道，减少握手延迟和资源消耗。适合高频短连接场景，如游戏和即时通讯，可提高吞吐量和连接稳定性，优化整体网络体验。
Sing-box 如何按端口匹配流量分配节点？
Sing-box 支持按端口匹配流量，将不同应用的流量分配到指定节点。结合策略组使用，可实现精准分流，优化访问速度和网络稳定性，提高整体网络体验。
Clash 的节点健康检测如何工作？
Clash 会定期对每个节点进行延迟和丢包率测试，并根据结果标记节点健康状态。结合策略组，可以自动切换到最优节点，避免访问高延迟或失效节点，提高整体网络稳定性和效率。
VMess AEAD 加密如何确保数据传输安全？
AEAD 加密可防止数据篡改、重放攻击和流量特征泄露。在高封锁环境中保证节点可用，提升数据安全和连接稳定性，降低被检测风险，确保长期安全访问体验。
Mihomo 节点分组功能有什么优势？
分组管理可按延迟、地区或用途分类节点，并结合策略组实现自动分流。用户可快速选择最优节点，提高访问速度和稳定性，方便管理大量节点并优化维护效率。
Sing-box 如何按 IP 段实现智能分流？
Sing-box 支持根据 IP 段匹配流量，将国内流量直连、国外流量走代理。结合策略组和规则文件，实现精细化流量管理，保证访问速度和稳定性，同时提高节点使用效率。
Hysteria2 的拥塞控制算法是什么？
Hysteria2 基于 QUIC 协议，采用 BBR 拥塞控制算法。相比传统 TCP 机制，BBR 能更好地利用带宽资源，提高高延迟网络下的吞吐率和响应速度。
